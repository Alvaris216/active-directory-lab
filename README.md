# active-directory-lab
This project demonstrates hands-on experience with Active Directory administration in a virtual lab environment.
## Lab Setup
- Windows Server 2022 (Domain Controller)
- Windows 11 Client Machine
- Oracle VirtualBox

## Key Tasks Performed
- Created domain users using Active Directory Users and Computers
- Performed password resets and account management
- Simulated account lockouts and unlocked users
- Created and managed security groups
- Joined a Windows 10 machine to the domain
- Tested domain user login authentication

## Skills Gained
- Active Directory Administration
- User & Group Management
- Troubleshooting Authentication Issues
- Virtualization (VirtualBox)
- Windows 11 proficiency
